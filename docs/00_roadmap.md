# 从不会写到能独立完成综合题

主线始终先学C，再用同题C++比较。一次练习按以下顺序做：读题和输入限制 → 用纸写一组正常数据与边界数据 → 写出状态变量含义 → 实现C → 核对输出 → 解释错误 → C++改写。不要把“看懂代码”当作“会做题”。

这条路线暂不要求背包、KMP、皇后。不要挤占基础程序的独立编写时间。

## 完整学期路线

1. 第1–2周：环境、类型、控制结构；实验1。
2. 第3–4周：循环、数组、字符串、调试器；实验2。
3. 第5–6周：函数、局部/全局/static、递归；实验3。
4. 第7–8周：指针、动态分配、数组参数；实验4。
5. 第9–10周：结构体、链表、文件；实验5。
6. 第11–12周：订餐管理系统；实验6；拆分模块、补测试。
7. 第13周以后：二分→筛法→归并→前缀和→回溯/BFS→DP→KMP/高精度。

每周至少做一次“从空文件开始”的练习。用`git diff`记录自己如何修错，提交说明写清楚“为什么错”，不是只写“更新”。

## 四道自测门槛

- 基础门槛：不用编译器，解释`5/2`、`(double)(5/2)`、`5/2.0`为何不同。
- 数组门槛：输入全负数组仍能找对最大值；空数组不会访问`a[0]`。
- 指针门槛：画出变量、地址、指向对象，解释为何交换两个局部指针不等于交换对象。
- 综合门槛：从零完成“读10个数→筛素数→排序→输出”，再完成订餐记录增删改查。
