## S1阅读定位

|部分|PDF页|
|---|---|
|程序设计基础|2–3|
|顺序与输入输出|4–7|
|分支|8–14|
|循环|15–23|
|数组|24–34|
|函数|35–42|
|指针|43–61|
|结构体和共用体（含链表）|62–78|
|文件|79–82|
|附加题1–94|83–102|
|模拟一 / 二 / 三|103–109 / 109–115 / 115–121|
|答案区|122–133|

答案区主要是前八单元的选择、读程序和填空，并非所有编程题、附加题、模拟卷都给了标准实现。S2含答案也可能有误。仓库对已有答案先核对其题意；无答案题提供推导和教学参考实现，不冒充校方标准答案。

## 证据层级

1. 原PDF题干、要求与给出的答案：保留原文可核对，答案也接受勘误。
2. C99/C++11的语言规则：用来判断资料中的语法、行为和标准依赖。
3. 仓库重写实现与测试：证明所列输入范围内的已测行为，不证明原作者的全部意图。
4. 自编练习与拓展：明确标注，不混入原资料题数。

## 可复现

- 原PDF完整保存在`raw/`，含新上传实验报告；SHA-256保存在`data/source_manifest.json`。
- `python3 tools/extract_sources.py`重新抽取（可选依赖PyMuPDF）；正常构建无需安装它。
- `python3 tools/search_sources.py 素数`检索所有资料，并输出来源和PDF页。
- `python3 tools/analyze_sources.py`重建分节统计、关键词页命中及题号候选。
- 自动抽取可能打乱公式、标点、下划线和双栏代码；不直接编译抽取文本。重点错误已结合页面渲染复核，未声称逐行校订全部原PDF。

## 标准固定为C99 / C++11

本仓库按用户要求选择标准，不沿用VC6.0或资料偶然使用的扩展。若原题答案依赖C90或某个旧编译器，会写出其历史语境。例如C99合法的VLA，在旧题中可能被当作非法；考试若明确指定旧标准，需按题目条件说明差异。
