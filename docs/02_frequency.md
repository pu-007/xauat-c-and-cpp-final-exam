# 资料题量、题型与复习优先级

统计的是这批上传资料，不能据此推断西建大历年真题概率。S3文件名写“真题”，但卷面标题写“模拟试题”，这里按模拟卷处理。没有考试年份序列、课程大纲或任课教师命题记录。

## 计数口径

- S1–S3按每节一级题号计题；同题跨资料重复保留，反映练习曝光量，不表示独立考次。
- 填空按题计，不按空计；S3简答1的5小问合为1题；S1模拟三最后一道编程3子问合为1题。
- S1 p122–133是答案，不重复计题；并非每道编程、附加题或模拟卷都附答案。
- S4是知识提纲，无统一题号；S5是教材例题与代码摘录，不和正式题库直接合计。
- 人工核对的分节题量保存在`data/section_counts.csv`；自动题号候选不参与统计。
