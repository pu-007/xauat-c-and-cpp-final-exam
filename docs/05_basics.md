# C99基础、类型、表达式与输入输出

对应S1第1–2单元、S2选择1–16、S3选择与简答、S4第1–2章。练习01、02、18。

先认识三个词：**对象**就是变量、数组等占用存储的数据；**类型**规定它能存什么、怎样运算；**标准**是判断代码是否合法的一套语言规则。

## 程序如何运行

```c
#include <stdio.h>                 /* 预处理包含声明 */
int main(void) {                    /* 托管环境的标准入口 */
    printf("Hello, C99!\n");        /* 调用标准库函数，不是语言内建输出语句 */
    return 0;                      /* 成功退出 */
}
```

编辑→预处理→编译→汇编→链接→运行。头文件声明接口；链接器连接实现。一个程序可由多个源文件组成；不是每个`.c`都必须有main。函数定义不能嵌套在函数内部，但调用可以嵌套。运行不会从“第一个写在文件里的函数”开始。

算法通常要求有穷性、确定性、有效性、零个或多个输入、一个或多个输出。输出是得到结果，不一定是printf。顺序、选择、循环是三种基本控制结构。

## 标识符、常量与对象

入门题常用规则：字母、数字、下划线；数字不能开头；关键字不能作普通标识符；区分大小写。`main/printf/scanf/define`不是C关键字，但不要随意重定义标准库名字；双下划线等保留名称应避开。

- `int n=3;`是定义并初始化；`n=4;`是赋值；`extern int n;`一般只是声明。
- 十进制`18`，八进制`022`，十六进制`0x12`均为18；`018`、`06d`非法；C99没有标准`0b1010`写法。
- `2.33e-1`合法；e前须有数，e后必须是带可选正负号的整数指数。
- `'a'`是整型字符常量（C中通常类型为int）；`"a"`是含`'a','\0'`的字符数组。
- `\n`换行、`\t`制表、`\\`反斜线、`\'`单引号、`\"`双引号、`\0`零字符。八进制转义最多三位；十六进制转义可继续吞入后续十六进制数字。
- `sizeof(char)==1`由标准保证；一字节的位数查`CHAR_BIT`，至少8。不能一概背`int=2,double=4`。
- 常见机器上`int`4字节、`double`8字节，但这是实现，不是C99普遍保证。

`<limits.h>`给整数范围，`<float.h>`给浮点精度；`<stdint.h>`提供可用时的精确宽度整数类型。`size_t`用来表示对象大小和数组长度，`sizeof`结果用`%zu`打印。C99新增/规范了`long long`、`//`注释、块中混合声明、for内声明、变长数组等；本仓库用固定上界或动态内存以方便与C++11对应。

## 转换与表达式

|表达式|结果/原因|
|---|---|
|`5/2`|2，整数除法向零截断|
|`-5/2`、`-5%2`|-2、-1；满足`a==(a/b)*b+a%b`（除数非0且商可表示）|
|`(double)(5/2)`|2.0；除法已经结束|
|`(double)5/2`|2.5；先将一个操作数转浮点|
|`(int)-2.9`|-2；向零截断，需结果可表示|
|`0<x && x<10`|正确区间判断|
|`0<x<10`|按`(0<x)<10`，结果总为真|
|`a=b=5`|右结合，最终表达式值5|
|`(a=3,a+2)`|按顺序执行，值5|

“不同类型总按精度高的转换”只是粗糙口诀：真实规则包括整型提升、有符号/无符号秩与范围。典型陷阱：`-1 < 1u`通常为假，因为-1转成unsigned。先保持运算中类型一致。

优先级实用顺序：后缀`[] () x++` → 一元`! ~ ++ * & sizeof` → `* / %` → `+ -` → 移位 → 关系 → 相等 → 位与/异或/或 → `&&` → `||` → `?:` → 赋值 → 逗号。不要死背后在复杂式子中冒险，补括号说明意图。

**优先级、结合性不规定一般操作数的求值先后。** C99用“序列点”描述副作用约束。`i++ + ++i`、`printf("%d %d",i++,i)`不是可移植输出题，存在未定义行为。`&&`、`||`、逗号运算符、条件运算符有相应的序列关系；函数实参之间的逗号不是逗号运算符。

有符号整数溢出是未定义行为；无符号整数按模运算。浮点有舍入误差。除数不能为0；`INT_MIN/-1`也可能溢出。不要把“一次运行出现的结果”当标准答案。

## 输入输出：格式与类型必须配对

|类型|scanf|printf|
|---|---|---|
|int|`%d`, `&x`|`%d`, `x`|
|long|`%ld`, `&x`|`%ld`, `x`|
|long long|`%lld`, `&x`|`%lld`, `x`|
|unsigned|`%u`, `&x`|`%u`, `x`|
|float|`%f`, `&x`|`%f`（可变参数提升为double）|
|double|`%lf`, `&x`|`%f`；C99中`%lf`与`%f`对printf等效|
|char|`%c`, `&c`|`%c`, `c`|
|字符数组|`%19s`, `name`（容量20）|`%s`, `name`|
|地址|一般不手动输入|`%p`, `(void*)p`|

`%8.2f`最小宽度8、小数2位；`%-8.2f`左对齐；宽度不截断过长数值。`%*d`在scanf中读取但不保存，不能为它提供一个对应指针。格式串普通字符要原样匹配：`scanf("%d,%d",&a,&b)`需要英文逗号。

`scanf(" %c",&c)`前导空白会跳过空格和换行；`scanf("%c",&c)`不会。`%s`跳过开头空白但只读一个单词；整行用`fgets`。scanf后的换行可能留在流里；最好一类输入方案贯穿一个练习，不用`fflush(stdin)`“清空输入”。每次检查返回的成功转换数。
