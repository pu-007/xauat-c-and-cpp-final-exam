# 选择、循环与读程序

对应S1第3–4单元、S2控制读程序1–21、S3简答与编程、S6实验1。练习03–09、32–33。

## 分支题怎么拿稳分

先把数轴画成不重叠、无遗漏的区间，再把边界变成条件。分段函数`x<0 / x==0 / x>0`适合if链；整数成绩等级适合`score/10`配合switch。百分制100必须单列或与9合并。

- 非0是真，0是假；关系和逻辑运算在C产生int类型0或1。
- else与最近的未匹配if配对；用花括号把意图写清楚。
- `switch`表达式是整数类型（包含字符、枚举）；case是整型常量表达式，不能重复；不是浮点区间。
- break退出最近一层循环或switch；没有break会向下贯穿，与后面的case是否再次匹配无关。
- switch自身不是循环，但若在循环中，其内部可以使用continue，作用于外层循环。

短路跟踪例：`m=2,n=2; (m=5>6)&&(n=7>8);`先算`5>6`得0，m变0，右侧跳过，n仍为2。

## 循环执行顺序

|结构|执行路径|容易出错|
|---|---|---|
|while|条件→体→条件|初始条件假时0次|
|do-while|体→条件→体|至少1次，末尾有分号|
|for|初值→条件→体→更新→条件|continue仍执行更新表达式|

读程序时画表，别在脑内同时记多个变量：

```c
int sum=10,n=1;
while(n<3) { sum-=n; n++; }
```

|轮次|进入时n|进入时sum|离开时n|离开时sum|
|---|---:|---:|---:|---:|
|1|1|10|2|9|
|2|2|9|3|7|

第三次条件不成立，最终`n=3,sum=7`。输出题还要检查空格、逗号与换行；`%d%d`会连起来。

循环改错顺序：初值→继续条件→状态是否推进→上下界→break/continue跳转→最后一次后的值。`for(...);`后的孤立分号会成为空循环体。`while(c=getchar()!='\n')`把0/1赋给c，应写`while((c=getchar())!='\n' && c!=EOF)`并用int保存c。

## 常见数值题模板

|题族|状态/递推|边界|
|---|---|---|
|求和|sum从0开始，按条件加|空集合和为0|
|乘积/阶乘|product从1开始|0!=1；范围防溢出|
|阶乘和|先`factorial*=i`再`sum+=factorial`|不要每次从1重算|
|拆位|`digit=n%10;n/=10`|0用do-while；负数先约定|
|水仙花|枚举100..999，拆三位并求立方和|不使用浮点pow做整数等式|
|素数|n<2直接否；试除到sqrt(n)|1不是素数|
|完数|累加小于自身的正因子|不把自身加进和；平方根因子只加一次|
|最大公约数|`(a,b)←(b,a%b)`|b为0时停止|
|分数数列|先加a/b，再将(a,b)更新为(a+b,a)|a,b用double或显式转换|
|π级数|符号交替，分母每次加2|项阈值乘4后才是π余项界|
|牛顿法|`x_next=x-f(x)/f'(x)`|导数接近0、迭代上限、收敛判据|

枚举算法先确定取值范围，再把题意翻译为约束。例如百钱百鸡/百马百瓦：枚举两类数量，用总数推出第三类，再检验总价；这样比三个循环更容易写对。歌德巴赫验证：对给定偶数枚举`p=2..n/2`，同时判定p和n-p；不能用有限实验“证明所有偶数”。

实验中的二次方程还要处理`a==0`退化为一次方程。计算判别式后分别处理两实根、重根、共轭复根；浮点判等要结合题意和数据尺度。初学考试按指定公式即可，数值稳定写法属于拓展。
