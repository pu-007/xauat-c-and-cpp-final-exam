# 数组、矩阵与排序

对应S1第5单元、S2数组读程序、S5排序/矩阵、S6实验2与4。练习10–14、25–26、34、36。

## 数组对象不等于指针变量

`int a[10];`含10个连续的int，合法元素是`a[0]..a[9]`。`a[10]`可以作为一步越界指针所指位置的表达形式，但不能访问为实际元素。未初始化的自动数组元素是不确定值；`int a[10]={0};`全部为0，部分初始化时剩余元素也补0。

C99支持块内变长数组，如`int n=10; int a[n];`。大小必须在求值时为正，VLA不能普通初始化；不是所有作用域都能定义VLA。C++11不支持标准VLA。本仓库采用固定容量+有效长度、malloc或vector。

数组不能整体赋值；结构体却可以。数组传给函数时多数情况下转为首元素指针，长度必须另传。在参数`int a[]`内部，`sizeof a`得到指针大小；只有仍是实际数组对象时，`sizeof a / sizeof a[0]`才给元素个数。

## 线性数组模式

- 极值：从第一个有效元素初始化，不能从0开始；并列时`>`保留首个，`>=`保留最后一个。
- 有序插入：从尾部向右搬，最后写入；先确认容量足够。
- 删除：从删除点开始向左搬，有效长度减1。
- 反转：交换`a[i]`与`a[n-1-i]`，只到`n/2`。
- 循环右移：k先模n；整体反转、前k反转、后n-k反转；n必须非0。
- 次大值：明确是否要求“不同于最大值”。先判是否存在，不能直接返回排序倒数第二个重复最大值。
- 频率/众数：若取值范围小可计数数组，否则排序后按连续段统计；并列众数都要输出时不要只保存一个。
- 差集/交集：题目可能是集合（去重）也可能是多重集（保留次数），先写清语义。

## 排序为什么有效

|算法|每轮保证|最坏时间|稳定性|用途|
|---|---|---|---|---|
|冒泡|当前最大值进入未排序区末端|O(n²)|严格大于才交换则稳定|填空、交换边界|
|选择|找最小值，与未排序区首交换|O(n²)|一般不稳定|下标维护|
|插入|前缀一直有序|O(n²)|严格大于才右移则稳定|近乎有序小数据|
|归并|左右有序后线性合并|O(n log n)|相等先取左则稳定|分治拓展|
|快速排序|围绕枢轴分区|最坏O(n²)，平均O(n log n)|一般不稳定|理解分区，考试按题目要求|
|希尔|按间隔做插入排序|依赖间隔序列|一般不稳定|S1附加81的拓展|

冒泡内层`j<end`保证`a[j+1]`不越界。选择排序不能无条件使用异或交换：当最小下标就是i，原地异或会把值清零；使用临时变量即可。

## 二维数组与矩阵

`int a[2][3]={{1,2,3},{4,5}};`最后元素自动补0。初始化可省第一维，后续维度必须可确定。按行连续排列：`a`多数情况下转为`int (*)[3]`，`a+1`跨一整行；`a[0]`转为int指针，`a[0]+1`跨一个int。

`a[i][j] == *(*(a+i)+j)`，但别用错误括号`*(a+i)[j]`代替。二维数组不是`int**`。函数可写`void f(int a[][3], int rows)`；C99还可写先提供维度的VLA参数，C++11则用array或vector。

常考任务：

- 转置：`b[j][i]=a[i][j]`；原地转置仅对方阵，且只交换一半。
- 主副对角线：`i==j || i+j==n-1`，中心只加一次。
- 行和/列和：每个独立行/列的累加器要重置。
- 最大值位置：保存行、列；下标从0还是1按题意输出。
- 鞍点：本资料定义为“行最大且列最小”。存在并列行最大时逐个候选检查；先找到一个行最大再只查这一列可能漏解。
- 杨辉三角：两侧为1，内部`a[i][j]=a[i-1][j-1]+a[i-1][j]`；滚动数组应倒序更新。
- 矩阵乘法：`C[i][j] += A[i][k]*B[k][j]`，内维一致，累加从0开始。
- 魔方阵：奇数阶用右上移动法；4的倍数阶、单偶数阶另有构造，不能用奇数阶算法硬套。

S1的环形四项最大和：把位置用`(start+j)%n`访问；在26线性窗口的基础上拓展，不能遗漏首尾相连的窗口。
