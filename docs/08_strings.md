# 字符与字符串

对应S1字符串编程、S2选择41–43、S5元音与拼接、S6实验2–4。练习04、15–16、31。

`char s[]="hello";`容量6，strlen为5；`char s[5]={'h','e','l','l','o'};`不是零结尾字符串，不能直接传给`%s/strlen/strcpy`。C99允许`char s[5]="hello"`恰好不存结束符，C++11不允许这个初始化；无论哪种语言都别把无结束符数组当字符串。

```c
char mutable[]="abc";       /* 可以改mutable[0] */
const char *literal="abc";  /* 不要修改字符串字面量 */
```

C允许用`char *`指向字面量但修改仍未定义；C++11不允许把字符串字面量转换成可写char指针。数组名不可重新赋值；`s="new"`不是字符串复制。

## 常用函数的前提

|函数|作用|必须满足|
|---|---|---|
|strlen|直到第一个零字符前的字节数|可读范围内存在零字符|
|strcpy|复制包含末尾零字符|目标容量>=源长+1，不能重叠|
|strcat|追加包含零字符|目标已有有效字符串，容量>=两长度+1|
|strcmp|按首个不同unsigned char比较|只保证返回负/0/正，不保证恰为-1/1|
|strchr|找字符|返回指针或NULL|
|strstr|找子串|空模式返回文本起始位置|
|fgets|最多读容量-1个字节并补零|可能保留换行；满行可能未读完|

`gets`即使在C99还存在，也无法提供容量限制，不使用。`strncpy`不是自动安全的strcpy：源过长时可能不补零；别只机械替换函数名。

## 手写四种题

1. 长度：让索引从0走到`'\0'`；返回size_t。
2. 拼接：先找到dest结束位置，再用另一个索引复制src，**最后立即在新末尾补零**。S5的`str1[j]`与固定`str0[40]='\0'`都是易错点。
3. 比较：相等且未结束时两指针一起走；遇不同用unsigned char的顺序比较。若题目明确要求字符编码差，则返回两字节之差；15为了演示标准strcmp语义只归一化为-1/0/1。
4. 回文：比较左右两端，向中间靠拢；空串、单字符串通常定义为回文。不要将`size_t n=0`后的`n-1`误作合法下标。

元音筛选用独立写指针/下标，只在命中时增加；遍历应在字符串结束处停止，不能盲目读固定100个字节。字符排序只排`strlen(s)`个字符，不排末尾零字符。

## 状态机与数字解析

统计单词：状态只有“词外/词内”；空白使状态变成词外，非空白且之前词外才计数。S5只把普通空格作分隔，16推广到isspace定义的空白，二者语义有明确区别。

从`a123x456 7`提取数字：扫描时遇数字做`value=value*10+(c-'0')`；从数字段走到非数字段时保存；末尾若仍在数字段还要保存一次。乘10前检查范围；不能直接把任意长数字塞进int。

C99的`strtol`比atoi适合可靠解析：先令errno=0，读取endptr，检查是否读到数字、是否有不允许的尾部字符、是否ERANGE，再检查INT_MIN..INT_MAX。实验要求手写my_atoi时要明确是否接受符号、空格及溢出，不能默默假设都合法。

C++11：`std::string`负责内存，`getline`读整行，`+`拼接，`==/<`比较内容，`size()`仍是字节数；字符串下标不自动保证安全，`.at()`会做边界检查并抛异常。
