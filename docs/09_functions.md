# 函数、作用域、存储期、递归与模块

对应S1第6单元、S2函数题、S6实验3。练习08、17–18、24、36。

## 从函数契约开始

```c
int is_prime(int n);                /* 声明：说明签名，调用者先看到它 */
void swap(int *a, int *b);           /* 约定两个指针都指向有效int */
size_t filter(const int *src, size_t n, int *dest); /* dest容量至少n */
```

定义才包含函数体。返回类型由声明/定义指定，不由return表达式临时决定；return会进行相应转换。C99不能省略返回类型，也不能隐式声明未声明的函数。`int f(void)`明确没有参数；C99中的`int f()`表示参数未指定，不等同于带原型的无参函数；C++11中`f()`表示无参数。

C参数**全部按值传递**。传指针是复制地址值，函数通过这个地址可修改外部对象。若要修改调用者的指针本身，要传二级指针，或返回新指针再赋回。数组参数调成指针，实际没有复制整个数组。

## 三个维度不要混淆

|声明|作用域|存储期|链接|
|---|---|---|---|
|块内普通变量|该块|自动|无链接|
|块内static|该块|静态，整个程序期间|无链接|
|文件作用域普通变量|从声明到文件末尾|静态|通常外部链接|
|文件作用域static|从声明到文件末尾|静态|内部链接，仅本翻译单元（通常是一个.c预处理后的内容）|
|malloc对象|通过有效指针访问|分配存储期，直到free|对象名不存在|

全局/静态对象默认零初始化；未初始化自动对象不能当成0用。局部变量可遮蔽外层同名变量。C99的auto是存储类说明符，不是C++11的类型推导。register是优化建议并限制对该对象取地址，现代优化器不依赖它决定寄存器分配。

局部static只初始化一次。先写`a=f(); b=f();`再打印，避免把两个有共享状态的调用放进实参列表后猜先后。实验3要求全局数组时可用全局数组完成教学任务；工程中更推荐参数显式传递依赖。

## 递归三问

1. 什么时候直接返回？这就是递归基。
2. 子问题是否严格变小？否则可能无穷递归。
3. 子问题结果如何组合？例如幂、阶乘、数组最大值。

阶乘递归深度n且会溢出；斐波那契朴素双递归重复计算导致指数时间。记忆化或从小到大递推能降到O(n)。快速幂24每次指数减半，只递归计算一次half；写两个相同递归调用会失去优化。

勒让德多项式题：先处理`P0=1,P1=x`，再套原题递推；要注意除法类型和两条基础分支。递归不是越多越高级，要比较栈空间、重复工作与可读性。

## 多源文件工程

头文件放声明、类型和包含保护，不放会在多个文件重复定义的普通全局对象。一个.c定义全局对象，其他.c用extern声明。函数内部使用的辅助函数可声明为static。

```c
/* math_utils.h */
#ifndef MATH_UTILS_H
#define MATH_UTILS_H
int is_prime(int n);
#endif
```

```bash
gcc -std=c99 -Wall -Wextra main.c math_utils.c -o app
```

宏是文本替换：`#define SQR(x) ((x)*(x))`对`2+3`有效，但`SQR(i++)`仍会重复修改。优先写函数或C99的合适inline函数；理解定义/链接规则后再在头文件用inline。C++11可用constexpr或模板函数。`#if/#ifdef`用于条件编译；`#include`不是运行时读取文件。
