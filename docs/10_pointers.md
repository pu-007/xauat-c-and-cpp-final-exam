# 指针：用对象、地址、类型三件事理解

对应S1第7单元、S2指针题、S4 p4–5、S6实验4。练习11、14、17、20、23。

```c
int x=10;
int *p=&x;   /* p保存x的地址；定义中的*表明类型 */
*p=20;       /* 表达式中的*解引用，修改x */
```

`p`是地址，`*p`是指向对象的值，`&p`是指针变量自己的地址。指针的类型决定解引用含义与步长。空指针可比较但不可解引用；未初始化指针不能当成可用地址。打印用`printf("%p",(void*)p)`。

## 声明辨析

|声明|含义|
|---|---|
|`int *p[3]`|3个int指针组成的数组|
|`int (*p)[3]`|指向包含3个int的一行数组的指针|
|`int (*f)(int,int)`|指向接收两个int并返回int的函数|
|`int *f(int)`|接收int并返回int指针的函数|
|`const int *p`|不能通过p修改所指int，p可以改指向|
|`int *const p=&x`|p不能改指向，可通过p修改x|
|`const int *const p=&x`|两种修改都受限|

从标识符开始，先看括号与右侧`[]/()`，再看左侧`*`。函数指针调用可写`f(a,b)`或`(*f)(a,b)`，参数类型必须兼容。

## 四个相似表达式

|表达式|含义|
|---|---|
|`*p++`|`*(p++)`，先取原对象值，再把指针前移|
|`(*p)++`|指向对象的值加1|
|`*++p`|指针先前移，再取值|
|`++*p`|所指对象先加1，表达式得到新值|

运算后是否还能解引用由边界决定。指针算术只在同一数组对象或其末尾后一位置范围内合法；末尾后一位置可用作循环终点，不可解引用。两个指针相减只适用于同一数组对象；结果类型ptrdiff_t，用`%td`。不能把不同对象地址的偶然顺序当算法依据。

数组多数上下文会转换为指针，但`sizeof a`、`&a`等场景不会。`a`本身不是“可自增的地址变量”。二维数组`int a[2][3]`不可以传给`int**`；它的行不是独立的指针对象。

## 动态内存

```c
int *a=malloc(n * sizeof *a);
if(a==NULL) { /* 处理分配失败 */ }
/* 只访问0..n-1并初始化每个要读取的元素 */
free(a);
a=NULL;
```

分配前保证n合法且乘法不超过SIZE_MAX。malloc不初始化；calloc按字节清零；`realloc`可能移动内存，先存临时指针，失败时原对象仍在，不能直接覆盖唯一指针。free只能用于匹配的分配起始指针或NULL；不能重复free，不能释放栈数组，释放后不能继续访问。令一个指针为NULL不会修复其他悬空别名。

返回局部数组地址是错误；返回malloc对象需要说明谁负责free。改变链表头用`struct Node **head`，而不是只改一份局部头指针。

C++11对应：vector/string负责常见数组需求，unique_ptr表达唯一所有权；std::move移动所有权时源对象仍存在但状态需遵循其类型规则。不要混用malloc/free与new/delete；`new[]`配`delete[]`。
