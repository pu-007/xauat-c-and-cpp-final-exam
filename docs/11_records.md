# 结构体、共用体、枚举与链表

对应S1第8单元、S2结构体题、S5成绩表、S6实验5–6。练习19–20、35与订餐综合项目。

```c
struct Student { int id; char name[20]; double score; };
struct Student s={1,"Li",90.0};
struct Student *p=&s;
/* s.score 与 p->score 与 (*p).score 指同一个成员 */
```

C99使用`struct Student`作类型名，或用typedef给别名。结构体可以嵌套另一个结构体，可以包含指向自身的指针，不能直接包含一个无限展开的自身对象。结构体赋值逐成员复制（包括成员数组），但若成员是指针，只复制地址，不复制所指对象。

`sizeof(struct)`受成员大小、对齐、填充影响，不一定等于成员大小相加。字段排序可能改变大小。结构体比较不能用`==`比较整体，也不要用memcmp比较含填充字节的逻辑相等性，应逐成员比较。

共用体成员共享存储，大小至少能容纳最大成员并满足对齐；不能无条件认为恰等于最大成员的原始字节数。35用枚举标签记住当前活动成员，避免把同一块字节按错误类型解释。C99枚举常量可用于switch；C++11的enum class作用域与类型检查更强。

## 成绩系统是一道综合题

输入学生→验证分数→求每人总分/均分→求每科均分→选最高者→按要求排序→输出。关键是区分“按学生行累计”与“按课程列累计”。

并列政策先确定：第一位、最后一位或全列出。成绩排序必须交换整条记录，不能只交换分数让姓名与分数脱节。稳定排序适合保持同分同学的输入顺序。名字长度按字节算，中文UTF-8一个字符通常不止一字节。

## 链表基本操作

|操作|关键顺序|陷阱|
|---|---|---|
|头插|`p->next=head; head=p;`|先覆盖head会丢失旧表|
|在q后插入|`p->next=q->next; q->next=p;`|保存后继再接入|
|删除q后结点|保存待删→重接→free|不能free后再读next|
|遍历|从head开始，遇NULL结束|必须推进p|
|逆置|保存next→反转next→推进前驱和当前|没保存next会断链|
|销毁|保存next→free当前→推进|不要漏掉最后一个结点|

头结点/哨兵并非同一概念：不带哨兵时head指首个数据结点；带哨兵时head可能指不存业务数据的结点。题目画图时先识别是哪一种。删除所有匹配项要能处理连续匹配、删除首尾、空表、全部删除。

有序链表合并用两个指针，每次取较小结点，O(n+m)，不用重新排序。两个按指数降序的多项式链表相加同理：指数相同则系数相加，和为0可不保留；指数不同先处理较大指数。数组、链表分别适合什么访问模式，也应能解释。
