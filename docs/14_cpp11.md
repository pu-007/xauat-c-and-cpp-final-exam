# C99到C++11：同一道题，两种语言习惯

C++不是“换了后缀的C”。先用C掌握对象与内存，再用C++管理资源和抽象。仓库全部以C99和C++11编译；**没有使用C++14/17的generic lambda、make_unique、structured binding、variant、std::gcd**。

|主题|C99|C++11|
|---|---|---|
|输入输出|stdio格式串，需手动配类型|iostream流推断类型，iomanip控格式|
|布尔|`<stdbool.h>`的bool/true/false宏|内建bool|
|字符常量类型|`'a'`为int|`'a'`为char|
|字符串字面量|不能修改；历史上可赋char*|类型含const，不能赋给char*|
|数组长度|可用VLA，但须满足限制|无标准VLA；用vector|
|结构体名称|`struct Student`或typedef|可直接Student|
|参数|全部按值，包括指针|另有T&、const T&引用|
|内存|malloc/calloc/realloc/free|vector/string/unique_ptr；必要时new/delete|
|void*|可隐式转换为其他对象指针|需显式转换；更推荐避免裸分配|
|空指针|NULL或空指针常量|nullptr避免重载歧义|
|const整数|通常不构成C整型常量表达式|适当初始化时可用于编译期整型上下文|
|函数|没有函数重载、默认参数|支持重载、默认参数、模板|
|auto|自动存储类|根据初始化表达式推导类型|
|函数参数`f()`|未指定参数列表|无参数|

## 从手动管理到容器

```cpp
std::vector<int> a(10, 0);              // 十个0
for (int& x : a) std::cin >> x;         // 引用修改元素；少了&就改副本
std::sort(a.begin(), a.end());          // 半开区间[begin,end)
a.erase(std::unique(a.begin(), a.end()), a.end()); // 先排序才能去除全部重复值
```

vector.size()是无符号size_t，空容器时`size()-1`会下溢；用范围for或明确的有效长度。reserve只预留容量，不增加元素个数，`reserve(10);a[0]=1;`仍越界；resize才创建元素。

std::array固定长度且可整体赋值、返回；std::string的`==`比较内容。C的`char* == char*`比较地址。std::accumulate用`0LL`初始化才能以long long累计。

## 引用、const与接口

`void swap(int& a,int& b)`通过引用改调用者；`double average(const std::vector<int>& a)`既不复制大数组也不允许修改元素。引用必须初始化，之后不能改成引用另一个对象；指针可为空或改指向。引用不延长所有对象的寿命，不返回局部变量的引用。

C++11类型推导不会自动保存引用：`auto x=a[0]`是副本，`auto& x=a[0]`才是引用。`static_cast<double>(sum)/n`比C风格转换表达意图更明确。

## 类、构造与RAII

类可以把数据与操作放一起，用private隐藏不变量，public暴露合法操作。构造函数建立有效状态，析构函数释放资源。RAII的含义是对象生命周期管理资源，因此提前return或抛异常也能释放。

20用forward_list，21用unique_ptr+关闭器管理FILE。C++11若需要唯一指针可写`std::unique_ptr<T> p(new T(...));`；`std::make_unique`是C++14，不能在本仓库使用。尽量直接用vector而非自行管理`unique_ptr<T[]>`的长度。

拥有裸资源的类若默认复制会双重释放，需要考虑拷贝/移动/析构（Rule of Five）；更好的入门习惯是让成员本身使用标准容器，遵循Rule of Zero。std::move只是将表达式转成可移动类别，不保证发生移动；移动由相应类型的构造/赋值实现。

## lambda、模板与迭代器

```cpp
std::stable_sort(students.begin(), students.end(),
    [](const Student& a, const Student& b) { return a.average > b.average; });
```

比较器须满足严格弱序，不能把`>`随意改`>=`。C++11 lambda的参数必须写具体类型；`[](auto x)`属于C++14。`[]`不捕获外部局部变量，`[&]`按引用捕获可能导致悬空，`[=]`按值捕获。

模板让相同算法适用于不同类型：`template<class T> T maximum(T a,T b){ return a>b?a:b; }`。先理解具体int版本，再学模板约束与编译错误。C++11的constexpr函数体受到严格限制；本仓库平方函数只有一条return，符合标准。

## 什么时候保留C写法

考试明确要求指针、链表、手写strlen、选择排序时，库函数不能替代评分点。C++实践版可以用标准容器改善接口，但你仍要能写出C版并解释复杂度。没有必要把每个十行程序包装成多层类。
