# 把算法真正练会：六个小推演

阅读13章后，用本章把“记住代码”转化为“能从状态重新推导代码”。每段都有原程序编号，不需安装额外库。

## 1. 二分13：为什么返回第一个2

数组`[1,2,2,4,9]`，目标2，候选区间是半开区间`[left,right)`。

|步骤|left|right|mid|a[mid]|动作|
|---|---:|---:|---:|---:|---|
|1|0|5|2|2|可能是答案，令right=2|
|2|0|2|1|2|继续向左寻找，right=1|
|3|0|1|0|1|太小，left=1|
|结束|1|1|—|—|第一个>=2在下标1，再检查相等|

为什么不是`right=mid-1`？因为right是“开端点”，当前mid仍可能是答案，写成闭区间的更新会打破不变量。练习目标0、3、10和空数组，逐一列出最终left。

## 2. 0/1背包27：为什么容量要倒着走

容量4，物品依次是`(重量2,价值3)`、`(3,4)`、`(2,5)`。`dp[c]`表示容量最多c的最优价值，允许不装满。

|处理后|dp[0]|dp[1]|dp[2]|dp[3]|dp[4]|
|---|---:|---:|---:|---:|---:|
|无物品|0|0|0|0|0|
|第1件|0|0|3|3|3|
|第2件|0|0|3|4|4|
|第3件|0|0|5|5|8|

转移为`dp[c]=max(dp[c], dp[c-weight]+value)`。第三件处理c=4时读到旧dp[2]=3，得到8；之后才更新dp[2]=5。如果正序更新，就可能在同一轮用新dp[2]=5更新dp[4]=10，把第三件选了两次。

若要求“恰好装满”，初值不能全部0，应把除dp[0]外设成不可达，并在转移前检查是否可达。状态定义变了，初始化就得变。

## 3. BFS29：队列就是距离层次

迷宫：

```text
0 1 0
0 0 0
1 1 0
```

起点(0,0)距离0。出队后发现(1,0)距离1；再发现(1,1)距离2；再发现(1,2)距离3；最后终点(2,2)距离4。入队时就写dist，这样一个格子不可能重复入队。

练习把终点改成墙，应该-1；把整个迷宫缩为一个可走格，应该0。若希望输出路径，发现邻居时保存前驱，从终点逆向回溯再反转。若边有不同代价，第一次入队不再保证最优，不可直接沿用这个证明。

## 4. 回溯28：做选择必须能撤销

N=4，假设第0行选择第1列，就占用列1、主方向对角线0+1=1、反方向对角线0-1+3=2。下一行只选未被三类标记占用的位置。

递归函数`search(row,n)`的承诺：进入时前row行已经合法摆好；返回值是在这个前缀下的完成方案数。到row==n时贡献1。一次分支返回后清除本行占用，恢复调用前状态，再尝试下一列。

不要用一个全局布尔量表示“已经找到解”就提前终止，因为本题要求全部方案数。N=2和N=3为0也是正常结果。N=8计数92包括对称方案，若题目要求本质不同解，还需对称去重。

## 5. KMP31：失配为什么不用回退文本

模式`ababca`的前缀函数为`[0,0,1,2,0,1]`。

已匹配`abab`后，如果下一字符不是c，不能直接忘记全部4个字符：`abab`的最长相同真前后缀是`ab`，因此j退到2，继续尝试模式第2位。回退链由`pi[j-1]`给出，不是简单j减1。

先自己写O(nm)的两重循环版本，用它作独立参考测试KMP；对随机短字符串比较结果，比仅比较两份同样思路的KMP更能找错。仓库测试用Python的find作为参考。

## 6. 高精度30：只是把竖式乘法交给数组

数字`120`低位在前存为`[0,2,1]`。乘以5：个位0*5=0；十位2*5=10，写0进1；百位1*5+1=6，最终`[0,0,6]`，逆序输出600。

不变量：每一位始终在0..9；carry保存尚未写入更高位的部分。每次算`digit[i]*factor+carry`仍用普通int，是因为这里factor<=1000、局部中间值有明确上界。高精度并不是任意中间计算都能无视溢出。

练习：把“乘小整数”替换为“两数组相加”，做S1附加77；再实现两数组比较。不要一开始就写所有四则运算。
