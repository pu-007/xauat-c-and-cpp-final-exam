# 期中与期末：哪些结论有依据

先区分“原卷事实”“统计结果”和“复习建议”。只有前两种是从资料直接得到的；建议是根据它们做出的学习安排。

## 期中资料：能确定什么

S3上传文件名是《24级大一C语言期中考试真题.pdf》，但PDF第1页标题是“C语言程序设计模拟试题”。因此可以确定它是一份带题目和分值的卷面资料，不能仅凭文件名证明它是正式真题。

|原卷事实|具体出处|能支持的复习结论|
|---|---|---|
|选择15题，共30分|S3 p1–2“一、选择题”|基础概念、语法辨认必须熟练|
|判断10题，共20分|S3 p2“二、判断题”|main、分支、循环、数组基础容易直接考概念|
|简答35分，其中表达式20分、三个读程序各5分|S3 p2–3“三、简答题”|表达式和手算执行顺序应优先练|
|编程15分，要求用switch转换成绩等级|S3 p4“四、编程题”|要能独立写完整switch，不只是会背等级区间|
|第14道选择存在C99语法问题|S3 p2选择14；已核对页面|应说明标准和题干缺陷，不能硬背一个选项|

这份卷偏基础，不能据此删掉期末的指针、结构体与文件。原卷逐题答案和推导在practice/s3_solutions.md；它们是本仓库推导，不是原PDF自带答案。

## 练习册统计如何使用

S2共125题，按每题一个主知识点人工标注：控制结构35题、数组27题、函数与存储17题、指针13题。标注表保留到“分节+题号”，见data/curated_topic_map.csv。

一道“用函数判素数”的题归到函数类，仍然也用循环。这个统计为了安排练习顺序，不代表各知识点完全独立。S1按章节统计，S2/S3按逐题主标签统计，两种口径不能直接混成一张“真实考频排行榜”。

## 考前怎么分配精力

1. 先做一次原S3基础卷，查类型、表达式、分支循环是否牢固。
2. 再练S1三套期末模拟中的编程题族，不把期中范围当期末范围。
3. 用自编100分卷限时验收，按错误类型补漏。
4. 基础题和综合题能独立完成后，再学习背包、KMP、皇后等拓展。

新的正式考试通知、教学大纲或老师明确范围，应优先于本仓库根据练习资料给出的建议。
