# 数据结构与算法：从期末题到拓展

这份路线以原资料中的数组、排序、函数、指针和链表为起点，适当延伸到常见数据结构和算法。先完成期末题型，再学习搜索和动态规划；后者属于拓展，不应当作原资料的考试频率。

## 第一层：从存储方式理解数据结构

|结构|怎样组织数据|典型操作及代价|仓库练习|
|---|---|---|---|
|数组|同类型元素按下标排列|访问已知下标 O(1)；查找无序值 O(n)；中间插入通常需搬移 O(n)|[数组极值](../practice/tasks/10_array_stats.md)、[矩阵行和](../practice/tasks/47_matrix_row_sums.md)|
|单链表|每个结点保存数据及下一结点地址|已知插入位置时改指针 O(1)；按值找结点通常 O(n)|[链表操作](../practice/tasks/20_linked_list.md)|
|栈|后进先出，只在一端操作|定长数组或链表的压栈、弹栈 O(1)；动态数组扩容时单次压栈可能为 O(n)|[53 栈与括号匹配](../practice/tasks/53_bracket_stack.md)|
|队列|先进先出，一端入队、另一端出队|数组环形队列或链表队列的入队、出队可为 O(1)|[迷宫广度优先搜索](../practice/tasks/29_bfs_maze.md)|
|哈希表|利用哈希函数将键映射到存储位置|平均查找通常为 O(1)，最坏情况可退化；需要处理冲突|C++11 可继续学习 `unordered_map`，练习词频统计|
|树与图|树用边组织层级；图用边表示一般关系|遍历复杂度与顶点数 V、边数 E 有关，邻接表遍历为 O(V+E)|先用迷宫格子理解图，再阅读下方外部教程|

数组下标直接定位；链表只能沿指针逐个走。链表在**已知位置**时插入是 O(1)，若还要从头查找该位置，总耗时通常是 O(n)。C 版需要考虑 `malloc/free` 和空指针；C++ 可使用 `vector`、`list` 或 `queue`，但考试要求手写结构时应按要求实现。

## 第二层：题目特征与算法选择

|题目特征|先考虑什么|核心思想与注意事项|练习|
|---|---|---|---|
|求和、最大值、统计|一次遍历|处理完前 i 项后，累积状态反映这 i 项；极值从第一个有效元素初始化|[10](../practice/tasks/10_array_stats.md)、[50](../practice/tasks/50_sign_count.md)|
|范围固定，逐个判断|枚举与筛选|候选范围要覆盖所有答案；先验证 0、1 和区间端点|[46](../practice/tasks/46_narcissistic.md)、[48](../practice/tasks/48_prime_interval.md)|
|要求升序或按成绩排名|冒泡、选择、插入排序|比较与交换改变局部顺序；相等记录是否保持顺序取决于算法|[12 三种排序](../practice/tasks/12_sort.md)、[19](../practice/tasks/19_students.md)|
|有序数组中查找|二分|先确定区间是闭区间还是半开区间，再统一更新边界|[13 二分查找](../practice/tasks/13_binary_search.md)|
|连续一段的和或最大值|前缀和、滑动窗口|前缀和可用两次相减求区间和；窗口右移时移出旧值、加入新值|[26 窗口](../practice/tasks/26_prefix_window.md)|
|每一步都有多个选择，要求完整方案|回溯|做选择→检查→递归→撤销；撤销是为了让下一分支从正确状态开始|[28 皇后](../practice/tasks/28_queens.md)|
|每一步代价相同，求最少步数|广度优先搜索 BFS|队列按距离层次扩展，发现新状态时立即标记；有不同边权时不能直接套用|[29 迷宫](../practice/tasks/29_bfs_maze.md)|
|许多子问题重复，能写出状态转移|动态规划|先定义状态，再确定初始值、转移和遍历顺序|[27 0/1背包](../practice/tasks/27_knapsack.md)|

复杂度是输入规模变化时所需工作或额外存储的增长趋势。常见顺序是 O(1)、O(log n)、O(n)、O(n log n)、O(n²)；它不是程序实际耗时的精确秒数。归并排序还需要额外数组；递归需考虑调用栈空间。细节见[算法阶梯](13_algorithms.md)和[逐步推演](18_algorithm_workshop.md)。

## 第三层：手算两个例子

**冒泡排序。** 输入 `[4,1,3,2]`，第一轮依次比较相邻元素，状态为 `[1,4,3,2]` → `[1,3,4,2]` → `[1,3,2,4]`。这一轮结束后最大值 4 到达末尾，下一轮只需处理前三项。完整代码：[12 排序](../practice/tasks/12_sort.md)。

**队列与 BFS。** 网格中 `0` 可走、`1` 是墙，只能上下左右移动：

```text
0 1 0
0 0 0
1 1 0
```

从左上角出发，依次发现 `(1,0)`、`(1,1)`、`(1,2)`、`(2,2)`，距离依次是 1、2、3、4。入队时标记已经访问，避免同一格重复入队。完整题目和边界：[29 迷宫](../practice/tasks/29_bfs_maze.md)。

## 外部学习资源

这些资源用于理解和练习；课程作业和考试请仍按题目要求使用指定语言与算法。外部页面可能包含比 C99/C++11 更新的语言特性，使用时要核对其标准版本。

- [Hello 算法](https://www.hello-algo.com/)：中文入门教程，有动画和多语言代码。建议从[数组与链表](https://www.hello-algo.com/chapter_array_and_linkedlist/)开始，再看栈、队列和排序。
- [VisuAlgo](https://visualgo.net/zh)：用动画观察[排序](https://visualgo.net/zh/sorting)、[链表](https://visualgo.net/zh/list)和[图遍历](https://visualgo.net/zh/dfsbfs)；可输入自己的数据，个别页面的中文翻译不完整。
- [OI Wiki](https://oi-wiki.org/)：中文算法知识库，适合基础掌握后查阅[数据结构](https://oi-wiki.org/ds/)和[排序性质](https://oi-wiki.org/basic/sort-intro/)；部分内容偏竞赛。
- [C 参考手册](https://en.cppreference.com/w/c) / [C++ 参考手册](https://en.cppreference.com/w/cpp)：查标准库函数、容器和语言版本；页面为英文，并同时收录新标准内容。
- [力扣题库](https://leetcode.cn/problemset/)：按数组、字符串、链表和排序等标签找练习；先做简单题，阅读题目要求后选择 C 或 C++。
