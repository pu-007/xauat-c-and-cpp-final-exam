1. [原S3卷解析](s3_solutions.md)：先打开原PDF限时做，再对答案。含无法按C99正常单选的题。
2. [自编100分模拟卷](mock_exam.md)：依据资料题型重新出题，**不是原校试卷**。

4. `tasks/`：45个配对示例对应的练习任务，只展示题意、输入约定、样例与挑战，不展示代码。
5. [错题本模板](mistakes.md)：把错误改写为一条可重复使用的规则。
