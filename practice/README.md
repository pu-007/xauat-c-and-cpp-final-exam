# 练习区

1. [原S3卷解析](s3_solutions.md)：先打开原PDF限时做，再对答案。含无法按C99正常单选的题。
2. [自编100分模拟卷](mock_exam.md)：依据资料题型重新出题，**不是原校试卷**。
3. [自编卷答案与评分点](mock_answers.md)：完成后再看。
4. [期末题型分阶段训练](exam_workbook.md)：按原资料的选择、读程序、填空、改错和编程题族练习，附解析和配对代码入口。
5. [53 组题目与代码目录](../docs/04_examples.md)：每题有具体要求、样例、解题步骤和 C/C++ 对照。
6. [错题本模板](mistakes.md)：把错误改写为一条可重复使用的规则。

推荐作答纪律：选择题每题不超过2分钟；读程序必须写状态表；编程题先写输入输出和边界，再写主体。测试时不要只运行题目样例。
