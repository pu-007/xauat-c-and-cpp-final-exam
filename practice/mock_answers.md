## B

1. `0 9`：左侧假，右侧不执行。
2. `2 5 5`：x读到2，p指向a[1]，再将该元素4加为5。
3. `12`：累加1+2+4+5。
4. `1 2`：局部static跨调用保留；两个调用分成独立完整语句。

每题5分；手算过程正确但抄错格式，可按训练标准扣1分（不是官方评分细则）。

## C

1. `j<end`；`a[j]>a[j+1]`。
2. `head`；`p`。顺序不能反：必须先保存旧链表入口。

## D

```c
int a[5],sum=0;
for(int i=0;i<5;++i) {
    if(scanf("%d",&a[i])!=1) return 1;
    sum+=a[i];
}
printf("%.2f",sum/5.0);
```

五处概念：初始化、下标区间、地址、累加、浮点除法且printf类型匹配。若数据可能很大，应把sum改long long并防溢出。
