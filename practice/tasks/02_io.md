# 02_io 格式化输入输出与类型

层级：基础。来源：S2 编程1–2；S4 p2。

## 任务

输入整数a与实数r，|a|<=10000、0<=r<=10000；输出a平方、圆面积和周长（PI=3.14）

## 样例

输入（空白表示无输入）：

```text
3 2
```

输出：

```text
9 12.56 12.56
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：scanf需要对象地址，printf需要值；double输入用%lf。

复杂度参考：O(1)。

挑战：换一组边界数据，先手算再运行。
