# 02_io 格式化输入输出与类型

层级：基础。来源：S2 编程1–2；S4 p2。

## 任务

输入一个整数 `a` 和一个非负实数半径 `r`，满足 `|a|≤10000`、`0≤r≤10000`。取圆周率为 3.14，依次输出 `a` 的平方、圆面积和圆周长；三个结果以空格分隔，面积和周长保留两位小数。读取失败或输入越界时以状态码 1 退出。

## 样例

输入（空白表示无输入）：

```text
3 2
```

输出：

```text
9 12.56 12.56
```

## 解题步骤

1. 输入 `3 2` 时，整数平方是 9；面积 `3.14×2×2=12.56`，周长 `2×3.14×2=12.56`。
2. 分别使用整数和 `double` 保存输入，计算平方、面积和周长；注意半径为 0 时两个圆的结果都为 `0.00`。
3. C 用 `scanf("%d%lf", &a, &r)` 传入地址，`printf` 的 `%.2f` 输出两位小数；C++ 用 `cin` 读取，用 `fixed` 和 `setprecision(2)` 控制输出。
4. 时间和空间均为 O(1)。本题的圆周率按原资料指定为 3.14。
