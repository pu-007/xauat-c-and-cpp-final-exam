# 03_grade switch百分制成绩

层级：基础。来源：S3 编程1；S2 编程4；S1 p14 编程6。

## 任务

输入0..100整数；输出A/B/C/D/E；范围外退出码1

## 样例

输入（空白表示无输入）：

```text
100
```

输出：

```text
A
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：按十位数分组，100单独并入A，break防贯穿。

复杂度参考：O(1)。

挑战：测试59/60/69/70/79/80/89/90/100；再改为if版本。
