# 03_grade switch百分制成绩

层级：基础。来源：S3 编程1；S2 编程4；S1 p14 编程6。

## 任务

输入一个 0～100 的整数成绩，用 `switch` 输出对应等级：90～100 为 A，80～89 为 B，70～79 为 C，60～69 为 D，0～59 为 E。只输出一个等级字符和换行；输入失败或成绩越界时以状态码 1 退出。

## 样例

输入（空白表示无输入）：

```text
100
```

输出：

```text
A
```

## 解题步骤

1. 先检查成绩范围，再用整数除法 `score/10` 得到十位分组。
2. 输入 100 时分组为 10，与分组 9 一起输出 A；8、7、6 分别输出 B、C、D，剩余合法成绩输出 E。
3. 每个已匹配分支用 `break` 结束，防止继续执行后面的分支。检查 59/60、69/70、79/80、89/90 和 100。
4. 时间和空间均为 O(1)。C 的 `scanf` 读取地址、`printf` 输出字符；C++ 使用 `cin`/`cout`，`switch` 与 `break` 的含义相同。
