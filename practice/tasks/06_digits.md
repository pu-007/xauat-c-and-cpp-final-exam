# 06_digits 数位拆分、水仙花数

层级：基础。来源：S1 p22 编程12、p120 编程1；S5 p6–7 水仙花数。

## 任务

输入一个 0～999999999 的整数。第一行依次输出它的位数、各位数字之和、倒序后的整数；第二行升序输出所有三位水仙花数。数字之间用单个空格分隔；倒序结果按整数输出，因此前导零不保留。输入失败或越界时以状态码 1 退出。

## 样例

输入（空白表示无输入）：

```text
120
```

输出：

```text
3 3 21
153 370 371 407
```

## 解题步骤

1. 对输入反复取 `%10` 得到末位，再用 `/10` 删除末位；每次累加数字并把倒序结果乘10后加上该位。
2. 输入 120 时依次取出 0、2、1，得到3位、数字和3、倒序整数21。输入0时使用 `do-while` 保证处理一次，输出 `1 0 0`。
3. 枚举100～999，拆出百位、十位和个位；三位的立方和等于原数时输出，结果为 `153 370 371 407`。
4. 数位处理时间 O(log(n+1))，枚举三位数为固定工作量，额外空间 O(1)。C 用 `scanf/printf` 和整数标记；C++ 用 `cin/cout` 和 `bool`。
