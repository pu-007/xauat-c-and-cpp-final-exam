# 06_digits 数位拆分、水仙花数

层级：基础。来源：S1 p22 编程12、p120 编程1；S5 p6–7 水仙花数。

## 任务

输入0..999999999；输出位数、数字和、倒序数字；再输出所有三位水仙花数

## 样例

输入（空白表示无输入）：

```text
120
```

输出：

```text
3 3 21
153 370 371 407
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：模10取末位，除10删末位；do-while正确处理0。

复杂度参考：O(log n)，枚举三位数为常数工作。

挑战：换一组边界数据，先手算再运行。
