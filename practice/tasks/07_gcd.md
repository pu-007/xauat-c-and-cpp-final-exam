# 07_gcd 欧几里得算法与最小公倍数

层级：基础。来源：S1 p22 编程11；算法优化。

## 任务

输入两个 0～10⁹ 的整数，依次输出它们的最大公约数和最小公倍数，以空格分隔。约定两个数都为0时两项均输出0；任一数为0时最小公倍数为0。读取失败或越界时以状态码 1 退出。

## 样例

输入（空白表示无输入）：

```text
12 18
```

输出：

```text
6 36
```

## 解题步骤

1. 利用 `gcd(a,b)=gcd(b,a%b)`，反复将 `(a,b)` 更新为 `(b,a%b)`，直到 `b=0`，此时 `a` 就是最大公约数。
2. 样例依次为 `(12,18)→(18,12)→(12,6)→(6,0)`，得到最大公约数6；先除后乘 `12/6×18=36` 得最小公倍数。
3. 两数都为0时不能除以最大公约数，单独输出0；输入在题设范围内时，先除后乘的结果可由 `long long` 保存。
4. 辗转相除在非零输入下需要对数级迭代，空间 O(1)。C 使用 `scanf/printf`；C++11 使用 `cin/cout`，两版都手写 `gcd`。
