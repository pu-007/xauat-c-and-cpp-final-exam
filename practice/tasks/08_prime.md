# 08_prime 素数判定与区间筛选

层级：基础。来源：S2 编程12；S5 p2/7；S1 模拟二编程1。

## 任务

输入-10^9..10^9的整数；输出0或1（是否素数）

## 样例

输入（空白表示无输入）：

```text
97
```

输出：

```text
1
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：非素数至少有一个因子<=平方根；d<=n/d避免d*d溢出。

复杂度参考：O(sqrt(n))，空间O(1)。

挑战：用函数筛选数组素数，再用12排序；对应S1模拟三最后一题。
