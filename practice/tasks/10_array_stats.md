# 10_array_stats 数组、平均数、极值与下标

层级：基础。来源：S2 改错2/编程8/13；S5 p3–5。

## 任务

n=1..100，再输入n个绝对值<=10^6的整数；输出最小值及首个下标、最大值及首个下标、平均数

## 样例

输入（空白表示无输入）：

```text
4
-5 3 3 1
```

输出：

```text
-5 0 3 1 0.50
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：极值初始化为首元素；sum用宽类型，平均数先转double。

复杂度参考：O(n)。

挑战：换一组边界数据，先手算再运行。
