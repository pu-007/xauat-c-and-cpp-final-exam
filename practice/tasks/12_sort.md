# 12_sort 冒泡、选择、插入三种排序

层级：提高。来源：S5 p2/p4/p6；S2 填空8；S1 p89 附加49。

## 任务

n=0..100，再输入n个int；三行分别输出三种升序排序结果

## 样例

输入（空白表示无输入）：

```text
5
3 -1 3 0 2
```

输出：

```text
-1 0 2 3 3
-1 0 2 3 3
-1 0 2 3 3
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：冒泡固定后缀，选择固定前缀，插入维护已排序前缀。

复杂度参考：最坏O(n²)，单个排序额外空间O(1)。

挑战：比较相等元素是否交换，解释冒泡/插入的稳定性及选择排序的不稳定性。
