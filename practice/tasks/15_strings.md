# 15_strings 手写strlen/strcat/strcmp、回文

层级：提高。来源：S1 p42 编程5–7、p120 编程2；S5 p7 My_strcat。

## 任务

输入两行英语字符串，每行<=100字节；输出拼接、长度、字典序比较符号、第一行是否回文

本题综合改编资料。两行可含空格或为空，按字节处理，约定输入不含 NUL，每行最多 100 字节。第一行输出拼接；第二行输出拼接长度、比较结果（小于/等于/大于分别 -1/0/1）和第一行是否回文（1/0，空串为回文）。

## 样例

输入（空白表示无输入）：

```text
abba
xy
```

输出：

```text
abbaxy
6 -1 1
```

推演：`abba` 与 `xy` 拼为 `abbaxy`，长度 6；a 小于 x 得 -1；首尾对称，因此回文结果为 1。

## 实践步骤

1. 分别读两行并去除换行，检查长度；C 字符数组预留结束符。
2. 在容量允许时依次拼接，计算长度；按首个不同字节比较字典序。
3. 将第一行首尾相向比较到一半；空串不进入循环，结果为真。
4. C 手写以 NUL 结尾的字符数组操作；C++ 用 string 与 equal。时间和存储均为 O(n+m)。

挑战：补写有容量参数的copy；不要把字符数组等同于字符串。
