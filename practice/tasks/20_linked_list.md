# 20_linked_list 动态内存、头插、删除、反转

层级：提高。来源：S1 p77–78 链表题、模拟三编程3；同类综合。

## 任务

n=0..100、删除目标；再输入n个int；按输入顺序建表，删除所有目标后反转输出

## 样例

输入（空白表示无输入）：

```text
5 2
1 2 3 2 4
```

输出：

```text
4 3 1
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：用二级指针统一删除头结点与普通结点；先保存next再释放。

复杂度参考：O(n)，空间O(n)。

挑战：换一组边界数据，先手算再运行。
