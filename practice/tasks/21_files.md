# 21_files 文件写入、读回与返回值

层级：提高。来源：S1 p79–82 文件单元。

## 任务

n=0..100及n个绝对值<=10^6整数；写入程序私有临时流，再读回输出总和

## 样例

输入（空白表示无输入）：

```text
3
4 -2 9
```

输出：

```text
11
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：不能用while(!feof)控制读操作；以fscanf成功数控制循环；检查ferror/fclose。

复杂度参考：O(n)。

挑战：换一组边界数据，先手算再运行。

完成后对照：[C99](../../src/c/21_files.c) / [C++11](../../src/cpp/21_files.cpp)。

```bash
./build/c/21_files < tests/cases/21_files.in
./build/cpp/21_files < tests/cases/21_files.in
```
