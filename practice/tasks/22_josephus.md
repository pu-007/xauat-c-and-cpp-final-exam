# 22_josephus 约瑟夫环：模拟到递推

层级：提高。来源：S1 p32 编程16、p77 编程3。

## 任务

n=1..10000,k=1..100000；输出从0编号的最终幸存者

## 样例

输入（空白表示无输入）：

```text
17 3
```

输出：

```text
10
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：删除一个人后重编号；f(n)=(f(n-1)+k)%n，从f(1)=0递推。

复杂度参考：O(n)，空间O(1)。

挑战：先用数组标记出局过程验证n=5,k=3；一基编号最后加1。

完成后对照：[C99](../../src/c/22_josephus.c) / [C++11](../../src/cpp/22_josephus.cpp)。
