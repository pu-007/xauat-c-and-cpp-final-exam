# 23 埃氏筛

本题是 S1 PDF 第 32 页编程 7 的素数判断思路的批量筛选改编，并非原题答案。

输入整数 n（0≤n≤100000），按升序输出所有不大于 n 的素数，数之间以一个空格分隔。n<2 时输出空行。

输入：
```text
20
```
输出：
```text
2 3 5 7 11 13 17 19
```
推演：2 从 4 开始划去偶数；3 从 9 开始划去其倍数；4 已被划去，且 5²>20，所以剩余未划去的 2～20 即为输出。

1. 初始化标记数组为零，从 2 起枚举 p，只处理未标记的 p。
2. 从 p² 开始以 p 为步长标记合数；更小的倍数已有更小素因子处理。
3. 枚举到 p>n/p 为止，输出所有未标记数。时间 O(n log log n)，空间 O(n)。

边界练习：输入 `0` 或 `1` 都输出空行，输入 `2` 输出 `2`；注意 0 和 1 即使未被标记也不是素数。

C 的 calloc 分配并清零，最后 free；C++ 的 vector 自动管理并初始化存储。对照 [C99](../../src/23_sieve.c) / [C++11](../../src/23_sieve.cpp)：
```bash
./build/c/23_sieve < tests/cases/23_sieve.in
./build/cpp/23_sieve < tests/cases/23_sieve.in
```
