# 25 归并排序

本题由 S1、S5 的排序内容拓展而来，并非原题答案。

输入 n（0～1000）以及 n 个 int 范围内的整数，按升序输出一行，数字之间以一个空格分隔；n=0 输出空行。要求使用归并排序，重复值也要保留。

输入：
```text
6
9 1 3 1 -2 5
```
输出：
```text
-2 1 1 3 5 9
```
推演：左右三项各自排序得到 [1,3,9] 和 [-2,1,5]，依次取两侧较小者合并；相等时先取左侧的 1，最终得到输出序列。

1. 将半开区间 [left,right) 分为两半；长度不超过 1 时直接返回。
2. 递归排序两半，双指针合并至辅助数组，取完任一侧后复制另一侧剩余元素。
3. 将辅助区间复制回原数组。时间 O(n log n)，辅助数组 O(n)，递归栈 O(log n)。

边界练习：`0` 输出空行；`1` 后接 `-3` 输出 `-3`；`3` 后接 `2 2 1` 输出 `1 2 2`。稳定性对带附加字段的相等记录才可直接观察。

C 传递数组与缓冲区；C++ 通过 vector 引用传递它们，避免复制。对照 [C99](../../src/25_merge_sort.c) / [C++11](../../src/25_merge_sort.cpp)：
```bash
./build/c/25_merge_sort < tests/cases/25_merge_sort.in
./build/cpp/25_merge_sort < tests/cases/25_merge_sort.in
```
