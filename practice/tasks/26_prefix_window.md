# 26 最大固定窗口和

本题是 S1 PDF 第 33 页编程 21 的线性数组拓展变式，并非原题答案。

输入 n、k（1≤n≤1000，1≤k≤n），再输入 n 个绝对值不超过 1000000 的整数。求连续 k 项的最大和及其最早起点，起点从 0 编号，两个整数同行以空格分隔。

输入：
```text
5 2
-4 2 3 -1 5
```
输出：
```text
5 1
```
推演：四个窗口和依次为 -2、5、2、4，最大值 5 的起点为 1。全负时也必须从第一个合法窗口初始化，不能将答案初始化为 0。

1. C 累计前缀和 prefix，起点 i 的窗口和为 prefix[i+k]-prefix[i]。
2. C++ 先求第一个窗口，右移时加新进入元素、减离开元素。
3. 仅在严格变大时更新最佳值和起点，保证并列取最早。两者时间 O(n)；C 前缀数组 O(n)，C++ 输入数组 O(n)、窗口额外状态 O(1)。

边界练习：`3 2` 后接 `-5 -2 -3` 输出 `-5 1`；`3 2` 后接 `1 1 1` 输出 `2 0`；当 k=n 时只有起点 0。

C 使用固定前缀和数组和 `scanf`；C++ 用 `vector` 保存输入、用 `cin` 读取，并通过滑窗复用上一次窗口和。对照 [C99](../../src/26_prefix_window.c) / [C++11](../../src/26_prefix_window.cpp)：
```bash
./build/c/26_prefix_window < tests/cases/26_prefix_window.in
./build/cpp/26_prefix_window < tests/cases/26_prefix_window.in
```
