# 27 0/1 背包

本题为自编算法拓展，未计入原资料考频。

输入物品数 n（0～100）和背包容量 W（0～1000），随后 n 行各输入重量和价值，重量为 1～1000000 的整数，价值为 0～1000000 的整数。每件物品最多选一次，总重量不超过 W；输出可取得的最大总价值。n=0 或 W=0 时答案为 0。

输入：
```text
3 4
2 3
3 4
2 5
```
输出：
```text
8
```
推演：第 1、3 件总重量 4、价值 8；第 2 件不能与其他任一件同选，单独价值 4，所以最优为 8。

1. 定义 dp[c] 为处理过的物品在容量 c 内的最大价值，初值均为 0。
2. 对每件物品从 W 到其重量倒序更新：dp[c]=max(dp[c],dp[c-weight]+value)。倒序使右侧仍是上一轮状态，每件最多用一次。
3. 输出 dp[W]。时间 O(nW)，空间 O(W)；重量大于 W 的物品自然跳过。

变式辨析：容量为 4、只有一件重量 2 价值 3 的物品时，0/1 背包答案为 3。若容量正序更新，`dp[4]` 会使用本轮刚更新的 `dp[2]`，得到错误的 6，相当于重复选择该物品。

C 使用固定数组和 if 比较；C++ 使用 vector 与 std::max。对照 [C99](../../src/27_knapsack.c) / [C++11](../../src/27_knapsack.cpp)：
```bash
./build/c/27_knapsack < tests/cases/27_knapsack.in
./build/cpp/27_knapsack < tests/cases/27_knapsack.in
```
