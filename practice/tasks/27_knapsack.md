# 27_knapsack 0/1背包动态规划

层级：拓展。来源：自编算法拓展，未计入资料考频。

## 任务

n=0..100,容量W=0..1000；n行正整数重量和0..10^6价值；输出最大价值

## 样例

输入（空白表示无输入）：

```text
3 4
2 3
3 4
2 5
```

输出：

```text
8
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：dp[c]是已处理物品在容量c内的最优值；容量倒序保证每物品至多用一次。

复杂度参考：O(nW)，空间O(W)。

挑战：把容量循环改成正序，找反例说明它变成完全背包。
