# 28_queens N皇后回溯

层级：拓展。来源：S1 p93 附加74八皇后的推广。

## 任务

n=1..10；输出所有合法摆放方案数（对称方案分别计数）

## 样例

输入（空白表示无输入）：

```text
8
```

输出：

```text
92
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：逐行选择列；列及两条对角线记录占用；返回上一层时撤销选择。

复杂度参考：保守上界O(n·n!)，空间O(n)。

挑战：换一组边界数据，先手算再运行。

完成后对照：[C99](../../src/c/28_queens.c) / [C++11](../../src/cpp/28_queens.cpp)。
