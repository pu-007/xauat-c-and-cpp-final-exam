# 29_bfs_maze 迷宫广度优先搜索

层级：拓展。来源：S1 p95 附加82：寻找路径的最短路拓展。

## 任务

行列1..20；矩阵0可走、1墙；从左上到右下四方向；输出最少步数，不通为-1

## 样例

输入（空白表示无输入）：

```text
3 3
0 1 0
0 0 0
1 1 0
```

输出：

```text
4
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：队列按距离分层；入队时标记，保证每格只入队一次。

复杂度参考：O(行×列)，空间同阶。

挑战：增加前驱数组恢复路径；有权边不能直接套普通BFS。
