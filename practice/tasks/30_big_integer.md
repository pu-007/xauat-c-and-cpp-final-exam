# 30_big_integer 十进制高精度阶乘

层级：拓展。来源：S1 p93 附加75、p94 附加77的大数思想。

## 任务

n=0..1000；输出精确n!

## 样例

输入（空白表示无输入）：

```text
25
```

输出：

```text
15511210043330985984000000
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：低位在前存每个十进制位；乘法逐位传播进位，绕开机器整数整体上限。

复杂度参考：O(n·D)，D为n!位数，空间O(D)。

挑战：换一组边界数据，先手算再运行。
