# 30_big_integer 十进制高精度阶乘

层级：拓展。来源：S1 p93 附加75、p94 附加77的大数思想。

## 任务

n=0..1000；输出精确n!

## 样例

输入（空白表示无输入）：

```text
25
```

输出：

```text
15511210043330985984000000
```

## 推演与步骤

计算精确阶乘，约定 0!=1；非法输入退出码 1。样例 25! 如上；先手算 5!：1→2→6→24→120，其低位在前数组为 [0,2,1]。

1. 以低位在前存储十进制各位，初始为 1。
2. 从 2 到 n 逐因子乘：当前位乘因子加进位，余数存当前位，商作为新进位。
3. 拆出剩余进位，最后逆序输出。设结果有 D 位，时间 O(nD)，空间 O(D)。

C 使用 3000 位定长数组，足以容纳 2568 位的 1000!；C++ 使用 `vector` 动态追加。
