# 31_kmp 字符串匹配：朴素法到KMP

层级：拓展。来源：S1 p61 编程8、p84 附加13的优化。

## 任务

输入文本和模式各一行<=1000字节；输出第一次匹配下标，未找到-1，空模式0

## 样例

输入（空白表示无输入）：

```text
abababca
ababca
```

输出：

```text
2
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：前缀函数记录最长相等真前后缀；失配时复用已经匹配的信息。

复杂度参考：O(n+m)，空间O(m)。

挑战：换一组边界数据，先手算再运行。

完成后对照：[C99](../../src/c/31_kmp.c) / [C++11](../../src/cpp/31_kmp.cpp)。
