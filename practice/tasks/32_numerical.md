# 32_numerical 数值迭代：莱布尼茨级数与牛顿法

层级：提高。来源：S5 p1–2 求π；S1 p23 编程22的求根变式。

## 任务

输入x，0<=x<=10^12；输出牛顿法sqrt(x)及以原资料1e-6项阈值求得的π（六位小数）

## 样例

输入（空白表示无输入）：

```text
2
```

输出：

```text
1.414214 3.141591
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：递推避免重复运算；迭代要有容差和次数上限；项误差不等于最终π误差。

复杂度参考：平方根有200次上限；π约500000项。

挑战：把sqrt结果与库函数比较；解释为何不能声称π精确到小数点后8位。
