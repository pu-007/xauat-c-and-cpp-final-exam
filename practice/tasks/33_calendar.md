# 33_calendar 闰年、日期结构体与年内序号

层级：基础。来源：S5 p1 闰年；S1 p84 附加15、结构体日期题。

## 任务

输入年1..9999、月、日；输出是否闰年、年内第几天；非法日期退出码1

## 样例

输入（空白表示无输入）：

```text
2000 3 1
```

输出：

```text
1 61
```
