# 39_saddle 矩阵所有鞍点

层级：提高。来源：S6实验2(3) p11–13。

## 任务

rows cols均1..10；输入整数矩阵；逐行输出每个行最大且列最小的鞍点：行 列 值，下标0起；无解NONE

## 样例

输入（空白表示无输入）：

```text
2 2
5 5
4 6
```

输出：

```text
0 1 5
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

提示：一个行内可能有多个并列最大；所有候选都检查，避免漏解。

复杂度参考：O(rc(r+c))；预处理行最大/列最小可优化到O(rc)。

挑战：换一组边界数据，先手算再运行。
