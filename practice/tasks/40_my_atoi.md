# 40_my_atoi 有范围检查的数字字符串转换

层级：提高。来源：S6实验4(2) p28/31；原my_atoi的安全扩展。

## 任务

输入一行最多100字节，可选+/-后接十进制数字，不接受空白；输出int或INVALID

## 样例

输入（空白表示无输入）：

```text
-1234
```

输出：

```text
-1234
```

## 实践步骤

1. 画出关键变量/数组状态，手算样例。
2. 从空文件独立实现C99版本。
3. 至少增加三个边界测试，并写出预期结果。
4. 解释时间/空间复杂度，再改写C++11版本。

复杂度参考：O(字符串长度)。
