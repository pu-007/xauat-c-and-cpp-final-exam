# 01_expressions 表达式、短路与确定的求值顺序

层级：基础。来源：S3 选择4/12、简答1；S2 选择10–16。

## 任务

无输入。依次计算并分行输出：(1) `5/2` 与 `5/2.0`；(2) 每次把 `a` 重置为 12 后，分别执行 `a+=a`、`a-=2`、`a*=2+3`、`a/=a+a`、`a%=(n%=2)`，最后一项的 `n` 初值为 5；(3) `m=n=2` 时执行 `(m=5>6)&&(n=7>8)`，输出表达式结果、`m` 和 `n`；(4) `x=3` 时将 `x++` 的旧值赋给 `old`，输出 `old` 和 `x`。各行数字之间用空格分隔。

## 样例

输入（空白表示无输入）：

```text

```

输出：

```text
2 2.5
24 10 60 0 0
0 0 2
3 4
```

## 解题步骤

1. 两个整数相除得到整数 2；除数为 `2.0` 时按浮点数相除，得到 2.5。
2. 每小问重新从 `a=12` 开始：依次得到 24、10、60、0；最后 `n%=2` 得 1，`12%1` 得 0。
3. 比较先于赋值：`5>6` 为 0，使 `m=0`；`&&` 短路，右侧不执行，`n` 仍为 2。后置自增先产生旧值 3，再使 `x` 变成 4。
4. 时间和空间均为 O(1)。C 的逻辑表达式结果是整数，使用 `printf`；C++ 的逻辑结果是 `bool`，用 `cout` 默认输出 0 或 1。
