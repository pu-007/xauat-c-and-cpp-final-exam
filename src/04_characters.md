# 04_characters 字母、数字、空格和其他字符统计

层级：基础。来源：S1 p22 编程3；S2 填空1/5；S5 p1 例3.10。

## 任务

读取一行单字节英语文本，直到换行或文件结束；分别统计字母、数字、普通空格和其他字符的个数，按该顺序用空格分隔输出。大写和小写字母都计入字母；制表符属于其他字符，换行本身不计入。空行输出 `0 0 0 0`。

## 样例

输入（空白表示无输入）：

```text
Ab9 !
```

输出：

```text
2 1 1 1
```

## 解题步骤

1. 四个计数器初始化为 0，逐个检查输入字符。
2. 样例 `Ab9 !` 中，`A`、`b` 是字母，`9` 是数字，空格和 `!` 分别属于后两类，所以输出 `2 1 1 1`。
3. C 用 `int` 接收 `getchar()`，才能区分 EOF；调用字符分类函数前转换为 `unsigned char`。C++ 用 `getline` 保存一整行，再逐字节分类。
4. 两版时间都是 O(n)；C 流式处理额外空间 O(1)，C++ 保存整行需 O(n)。本题只统计，不转换字母大小写。
