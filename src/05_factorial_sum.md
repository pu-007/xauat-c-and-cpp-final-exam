# 05_factorial_sum 阶乘递推与累加

层级：基础。来源：S1 p22 编程1/5、p120 填空4；S2 编程7/9。

## 任务

输入整数 `n`（0～20），输出 `n!` 和 `1!+2!+…+n!`，两数以空格分隔。约定 `0!=1`，没有加数时的和为 0，因此输入 0 应输出 `1 0`。读取失败或输入越界时以状态码 1 退出。

## 样例

输入（空白表示无输入）：

```text
5
```

输出：

```text
120 153
```

## 解题步骤

1. 将阶乘初值设为 1，累加和设为 0；依次处理 `i=1` 到 `n`。
2. 每轮先用上一次阶乘乘 `i` 得到 `i!`，再加入累加和。输入 5 时，阶乘依次为 1、2、6、24、120，和为 153。
3. 使用 `unsigned long long` 保存结果；本题约定的 0～20 范围内，阶乘和累加和均能表示。C 的 `%llu` 对应此类型；C++ 的输出流根据变量类型输出。
4. 时间 O(n)，额外空间 O(1)。对照输入 0、1、20，检查初始化与上界。
