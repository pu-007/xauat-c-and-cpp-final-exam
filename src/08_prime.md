# 08_prime 单个整数的素数判定

层级：基础。来源：S2 编程12；S5 p2/7；S1 模拟二编程1。

## 任务

输入一个 -10⁹～10⁹ 的整数，使用自定义函数判断它是否为素数。是素数输出 `1`，否则输出 `0`；负数、0和1都不是素数。读取失败或越界时以状态码 1 退出。

## 样例

输入（空白表示无输入）：

```text
97
```

输出：

```text
1
```

## 解题步骤

1. 小于2的数直接判为非素数；对其余数从2开始试除。
2. 只需试除到平方根：如果存在较大的因子，必有一个不大于平方根的配对因子。写 `d<=n/d` 可以避免 `d*d` 溢出。
3. 输入97时，2～9均不能整除它，因此输出1；检查 1、2、9 和 25 可覆盖定义、最小素数和完全平方数。
4. 对 `n≥2`，时间 O(√n)、空间 O(1)。C99 通过 `<stdbool.h>` 使用 `bool`；C++ 内置 `bool`，两版分别用格式化输入输出和流。
