# 09_recurrence 斐波那契与分数序列

层级：基础。来源：S5 p2 例5.8；S2 编程10。

## 任务

输入整数 `n`（1～90）。定义斐波那契数列 `F(1)=F(2)=1`、`F(n)=F(n-1)+F(n-2)`；同时计算分数序列 `2/1、3/2、5/3、8/5、…` 的前20项之和。输出 `F(n)` 和分数和，分数和保留六位小数，两个结果以空格分隔。读取失败或越界时以状态码 1 退出。

## 样例

输入（空白表示无输入）：

```text
10
```

输出：

```text
55 32.660261
```

## 解题步骤

1. 从 `F(0)=0`、`F(1)=1` 出发，每次先保存两数之和，再移动两个变量；输入10时得到 `F(10)=55`。
2. 分数序列从分子2、分母1开始：先将当前商加入和，再令下一分子为原分子与分母之和，下一分母为原分子；恰好处理20项，得到 `32.660261`。
3. 分子、分母用 `double` 才能执行浮点除法；递推前先保存新值，避免覆盖旧值。
4. 时间 O(n+20)，空间 O(1)。C 用显式类型与 `printf("%.6f", ...)`；C++ 用 `auto` 推导临时变量及 `fixed/setprecision(6)`。
