# 12_sort 冒泡、选择、插入三种排序

层级：提高。来源：S5 p2/p4/p6；S2 填空8；S1 p89 附加49。

## 任务

n=0..100，再输入n个int；三行分别输出三种升序排序结果

本题将资料中的排序知识综合改编。输入元素须在 int 范围内；n=0 时仍输出三个空行。输入无效以非零状态退出。

## 样例

输入（空白表示无输入）：

```text
5
3 -1 3 0 2
```

输出：

```text
-1 0 2 3 3
-1 0 2 3 3
-1 0 2 3 3
```

推演：冒泡首轮把一个 3 移到末尾；选择排序首轮选出 -1 放在首位；插入排序逐个把元素放入已排序前缀，三者最终均为 `-1 0 2 3 3`。

## 实践步骤

1. 读入 n 个元素并复制成三份，避免前一种排序影响后面的输入。
2. 冒泡比较相邻元素，将最大值逐轮移到后缀；一轮无交换即可提前结束。
3. 选择排序每轮将剩余最小值换到前缀末尾；插入排序将较大元素右移后放入待插元素。
4. 三种算法最坏时间 O(n²)，排序自身额外 O(1)，存储三份数据 O(n)。C 手动复制数组；C++ vector 可直接复制，选择排序用 min_element。

挑战：比较相等元素是否交换，解释冒泡/插入的稳定性及选择排序的不稳定性。

参考：本实现的冒泡和插入只移动严格大于的元素，相等元素保持先后，因而稳定；选择排序交换可能跨过相等元素，例如带标记的 `2a 2b 1` 第一轮变为 `1 2b 2a`，不稳定。
