# 16_words_vowels 单词状态机、元音筛选、字符排序

层级：提高。来源：S5 p3 单词数、p7–8 元音/字符排序；S1 p32 编程14。

## 任务

输入一行<=100字节；单词按空白分隔；输出单词数、原顺序元音、升序字符（含空格）

本题综合改编资料。输入为不含 NUL 的单行，最多 100 字节；单词是连续的非空白字符，元音只认英文 aeiou 的大小写。排序按无符号字节值，空格也参与；空行输出 0 和两个空行。

## 样例

输入（空白表示无输入）：

```text
hi a
```

输出：

```text
2
ia
 ahi
```

推演：`hi a` 有两个单词，按原顺序抽出 `i`、`a`；空格字节值最小，排序后为 ` ahi`。

## 实践步骤

1. 读一行，遇到空白离开单词；从空白进入非空白时计数。
2. 按输入顺序收集英文元音；对原字符按无符号字节升序排序。
3. 输出计数、元音和排序结果，各占一行；无元音时第二行为空。
4. C 用字符状态机及冒泡，C++ 用字符串流和 sort；两者均存储 O(n)，排序分别 O(n²)、O(n log n)。
