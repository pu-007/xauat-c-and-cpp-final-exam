# 21 临时文件写入和读回

本题改编自 S1 PDF 第 79～82 页文件单元，练习文件操作，并非原题答案。

输入整数 n（0～100）及 n 个绝对值不超过 1000000 的整数，将这些数写入程序私有临时文件，回到开头逐个读回并求和，输出一行总和。n=0 时输出 0；创建、写入、定位、读取或关闭失败时程序以非零状态结束。

输入：
```text
3
4 -2 9
```
输出：
```text
11
```
推演：文件依次写入 4、-2、9，读回累计和依次为 4、2、11。

1. 打开临时文件，逐个检查输入范围并写入；写入结束刷新并定位到开头。
2. 以读取成功作为循环条件，而不是预先判断文件结束；区分正常 EOF 和读错。
3. 检查关闭结果后输出 long long 总和。时间 O(n)，程序变量空间 O(1)，临时文件存储 O(n)。

边界练习：输入 `0` 输出 `0`；输入 `2` 和 `-1000000 1000000` 输出 `0`。写入到读回之间必须定位，不能只检查 `feof` 后再盲读。

C 用 FILE* 和显式 fclose；C++ 用带删除器的 unique_ptr 管理同一类 C 文件资源，正常路径 release 后关闭以检查错误。对照 [C99](./21_files.c) / [C++11](./21_files.cpp)：
```bash
./build/c/21_files < tests/cases/21_files.in
./build/cpp/21_files < tests/cases/21_files.in
```
