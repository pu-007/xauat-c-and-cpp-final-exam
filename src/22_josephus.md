# 22 约瑟夫环递推

本题改编自 S1 PDF 第 32 页编程 16、第 77 页编程 3 的报数问题，采用从 0 开始的编号及仅输出最后幸存者的约定。

n 人按 0～n-1 围成一圈，从 0 号开始报 1，顺序报到 k 的人出局，下一人重新报 1，直到剩一人。输入 n、k，1≤n≤10000，1≤k≤100000；输出幸存者的原始零基编号。

输入：
```text
5 3
```
输出：
```text
3
```
推演：依次出局 2、0、4、1，剩下 3。递推也得到 f(1)=0，f(2)=1，f(3)=1，f(4)=0，f(5)=3。

1. 仅一人时幸存编号为 0；删除首人后把下一人视为新编号 0。
2. 将规模 size-1 的结果映射回原环：f(size)=(f(size-1)+k)%size。
3. 迭代到 n 并输出；n=1 直接输出 0。时间 O(n)、空间 O(1)。

边界练习：`1 100000` 输出 `0`；`5 1` 输出 `4`。若题目要求从 1 编号，最后将本程序结果加 1。

C 用 scanf/printf，C++ 用 cin/cout，递推相同。对照 [C99](./22_josephus.c) / [C++11](./22_josephus.cpp)：
```bash
printf '5 3\n' | ./build/c/22_josephus
printf '5 3\n' | ./build/cpp/22_josephus
```
