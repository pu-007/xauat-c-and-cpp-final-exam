# 24 递归快速幂

本题是 S1 PDF 第 42 页编程 12 的递归主题拓展，并非原题答案。

输入非负整数 a、b（均不超过 10⁹），输出 a 的 b 次方对 1000000007 取模的结果。约定 a⁰=1，包括 0⁰=1。

输入：
```text
2 10
```
输出：
```text
1024
```
推演：递归计算 2⁵，再计算 2²、2¹、2⁰；回退依次得到 1、2、4、32、1024。

1. b=0 返回 1；否则递归一次求 a 的 b/2 次方的模。
2. 平方取模；若 b 为奇数，再乘 a 取模。long long 可容纳本题范围内的中间乘积。
3. 输出结果；b=0 直接命中基例。时间和栈空间均为 O(log(b+1))。

边界练习：`0 0` 输出 `1`，`0 5` 输出 `0`，`7 1` 输出 `7`。只递归一次计算半幂，避免重复求相同子问题。

C 用宏定义模数及 static 函数，C++ 用 constexpr 和 auto 推导中间变量；两者的递归式相同。对照 [C99](../../src/24_recursion.c) / [C++11](../../src/24_recursion.cpp)：
```bash
./build/c/24_recursion < tests/cases/24_recursion.in
./build/cpp/24_recursion < tests/cases/24_recursion.in
```
