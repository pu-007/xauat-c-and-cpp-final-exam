# 28_queens N皇后回溯

层级：拓展。来源：S1 p93 附加74八皇后的推广。

## 任务

n=1..10；输出所有合法摆放方案数（对称方案分别计数）

## 样例

输入（空白表示无输入）：

```text
8
```

输出：

```text
92
```

## 推演与步骤

每行放一个皇后，不能同列或同对角线，镜像和旋转分别计数。n=1 得 1，n=2、3 得 0；4 皇后的两个列序列为 2、4、1、3 和 3、1、4、2。样例 n=8 共 92 种。非法输入退出码 1。

1. 逐行尝试每列，以列、行加列、行减列检查冲突；行减列加 n-1 防止负下标。
2. 标记占用后递归下一行，递归返回撤销标记；放完所有行计数 1。
3. 汇总各分支计数。时间上界 O(n·n!)，空间 O(n)。C 用静态数组，C++ 用类和 `std::array` 保存状态。
