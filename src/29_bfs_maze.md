# 29_bfs_maze 迷宫广度优先搜索

层级：拓展。来源：S1 p95 附加82：寻找路径的最短路拓展。

## 任务

行列1..20；矩阵0可走、1墙；从左上到右下四方向；输出最少步数，不通为-1

## 样例

输入（空白表示无输入）：

```text
3 3
0 1 0
0 0 0
1 1 0
```

输出：

```text
4
```

## 推演与步骤

矩阵元素只能为 0 或 1，起点终点必须可走；起点是墙或终点不可达时输出 -1，单格可走时输出 0。非法输入退出码 1。样例路径为 (1,1)→(2,1)→(2,2)→(2,3)→(3,3)，共 4 步。

1. 距离初始化为 -1；可走的起点以距离 0 入队。
2. 取队首，检查四邻格，给未访问可走格赋距离并立即入队。
3. 队列按距离分层，首次访问即最短距离；输出终点距离。

时间和空间均为 O(行×列)。C 用两个数组模拟队列，C++ 用 `vector` 和 `queue<pair<int,int>>`。拓展：记录前驱恢复路径。
