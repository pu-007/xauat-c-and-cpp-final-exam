# 31_kmp 字符串匹配：朴素法到KMP

层级：拓展。来源：S1 p61 编程8、p84 附加13的优化。

## 任务

输入文本和模式各一行<=1000字节；输出第一次匹配下标，未找到-1，空模式0

## 样例

输入（空白表示无输入）：

```text
abababca
ababca
```

输出：

```text
2
```

## 推演与步骤

两行可含空格，长度按字节计算；下标从 0 开始，空模式得 0，不存在得 -1。样例先从下标 0 开始比较，失配后利用前缀信息回退，最终在下标 2 匹配 `ababca`。缺行或超长时退出码 1。

1. 计算模式每个前缀的最长相等真前后缀长度 `pi`。
2. 扫描文本，失配时将已匹配长度回退至 `pi[j-1]`，继续比较当前字节。
3. 匹配长度达到模式长度时输出起点，否则输出 -1。

时间 O(n+m)，前缀表 O(m)，输入缓冲 O(n+m)。C 用字符数组和 `fgets`；C++ 用 `string`、`getline` 和 `vector`。
