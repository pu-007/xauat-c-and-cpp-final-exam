# 32_numerical 数值迭代：莱布尼茨级数与牛顿法

层级：提高。来源：S5 p1–2 求π；S1 p23 编程22的求根变式。

## 任务

输入x，0<=x<=10^12；输出牛顿法sqrt(x)及以原资料1e-6项阈值求得的π（六位小数）

## 样例

输入（空白表示无输入）：

```text
2
```

输出：

```text
1.414214 3.141591
```

## 推演与步骤

输入 0～10¹² 的实数，输出平方根和级数算出的 π，均保留六位小数；非法输入退出码 1。x=2 时牛顿迭代从 2 得 1.5、1.416666…，最终输出 1.414214；级数结果为 3.141591。x=0 直接输出零平方根，避免除零。

1. 对非零 x 迭代 `(root+x/root)/2`，相邻差不超过新值绝对值的 10⁻¹² 倍或迭代 1100 次时停；相对容差可处理极小的正数。
2. 累加 `(-1)^k/(2k+1)`，遇到绝对值小于 10⁻⁶ 的项时停止且不加该项，再乘 4。
3. 项阈值不保证 π 六位小数正确，误差界需考虑乘以 4。

平方根最多 1100 次，级数约 500000 项，空间 O(1)。C 用 `fabs` 和 `printf`；C++ 用 `std::abs` 和流格式。
