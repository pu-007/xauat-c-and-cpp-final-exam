# 35_union_enum 结构体、共用体与枚举

层级：提高。来源：S1 第八单元；C++类型安全拓展。

## 任务

无输入；输出一个整数型记录及一个实数型记录

## 样例

输入（空白表示无输入）：

```text

```

输出：

```text
7
2.5
```

## 推演与步骤

本题为结构体、共用体和枚举知识的综合改编，无输入。整数记录的标签指定整数成员，打印 7；实数记录的标签指定实数成员，打印 2.5。共用体共享存储，不能通过另一成员推断原值；结构体大小也可能含对齐填充。

1. 定义两种类型标签，结构体保存标签和共用体。
2. 初始化两条记录时保证标签与写入成员一致。
3. 根据标签选择并输出相应成员。

时间和空间 O(1)。C 用普通枚举和指定成员初始化，C++ 用限定作用域的 `enum class` 和重载构造函数。

完成后对照：[C99](../../src/35_union_enum.c) / [C++11](../../src/35_union_enum.cpp)。

```bash
./build/c/35_union_enum < tests/cases/35_union_enum.in
./build/cpp/35_union_enum < tests/cases/35_union_enum.in
```
