# 36_prime_pipeline 综合压轴：素数筛选、函数、排序

层级：提高。来源：S1 p120–121 模拟三编程4。

## 任务

输入恰好10个-10^9..10^9整数；输出原数组与升序素数数组

## 样例

输入（空白表示无输入）：

```text
7 4 2 1 11 9 3 3 0 -5
```

输出：

```text
7 4 2 1 11 9 3 3 0 -5
2 3 3 7 11
```

## 推演与步骤

输入 10 个范围内的整数；第一行保留原顺序，第二行输出升序素数，重复值保留。没有素数时第二行为空行；非法输入退出码 1。样例筛出 7、2、11、3、3，排序得到 2、3、3、7、11。负数、0 和 1 均不是素数。

1. 排除小于 2 的数，再试除 2 到平方根；`d <= n/d` 避免平方溢出。
2. 将素数写入新数组并记录有效长度。
3. 仅排序有效部分，分别输出原数组和结果。

设输入数为 n、最大正值为 M、筛得 k 个素数，C 时间 O(n√M+k²)，C++ 时间 O(n√M+k log k)，空间 O(n)。C 手写筛选和冒泡排序；C++ 使用 `copy_if` 和 `sort`，考试指定函数或算法时应遵守题目。
