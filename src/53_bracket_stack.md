# 53_bracket_stack 用栈判断括号匹配

本题是学习数组、指针和数据结构后的拓展练习，不计入原资料的考试题量。

## 题目要求

输入一行最多 100 个字符，只包含 `(`、`)`、`[`、`]`、`{`、`}`。如果每个右括号都与最近的未匹配左括号同种配对，并且没有剩余左括号，输出 `1`；否则输出 `0`。空行视为匹配。超过长度、出现其他字符或没有读到输入行时，程序以状态码 1 退出。

## 样例

输入：

```text
{[()]()}
```

输出：

```text
1
```

依次把 `{`、`[`、`(` 压栈；`)`、`]` 依次与栈顶配对并弹栈；随后 `()` 配对，最后 `}` 与 `{` 配对，栈为空。输入 `([)]` 时，`)` 遇到的栈顶是 `[`，应输出 `0`。

## 解题步骤

1. 检查整行长度与字符是否符合输入要求。
2. 从左往右扫描：左括号压栈；右括号要求栈非空且与栈顶同种，然后弹出。
3. 扫描结束时栈为空才算匹配。输入 `)`、`((`、空行和长度为100的字符串检查边界。

时间 O(n)，额外空间 O(n)。C 用字符数组和下标 `depth` 模拟栈；C++ 使用 `std::stack<char>` 的 `push`、`top` 和 `pop`。两版都先验证输入，再判断匹配。
